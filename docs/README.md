# EUB KiCad Library Docs

This directory contains policy and usage notes for the shared EUB KiCad
library repository.

- `kicad_global_library_setup.md`: how to register this repository as KiCad global symbol and footprint libraries.
- `naming_conventions.md`: symbol, footprint, mechanical, and graphic naming rules.
- `contribution_notes.md`: rules for adding custom parts and recording verification status.
- `project_usage_notes.md`: how EUB projects should depend on this repository.
- `USAGE.md`: compact existing setup note retained for compatibility.
